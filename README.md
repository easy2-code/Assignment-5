# Assignment-5

Instructions:

1. Open the Figma Link and carefully study the layout, typography, buttons, colors, and responsiveness.
2. Create a new HTML file named index.html.
3. Use Bootstrap 5 CDN for styling.
4. Your design must include:
   A responsive Navbar

   A 3-column layout using the Bootstrap Grid system (for services, features, or cards)

5. Use only Bootstrap classes (no custom CSS unless absolutely necessary).
6. Make sure the layout is responsive on all screen sizes (mobile, tablet, desktop).
